# 已知边界

- 主要输入是已完成的 v1.3 增强报告包，须保留 SQLite、概览、验证记录和配套窄索引 CSV。原 schema 1.2 报告走现有增强步骤。RC 没有直接摄取任意原 JSON 或任意外来 trace 的入口。
- 历史数据缺少真实可比的 baseline 绑定与目标环境，不授予确认影响。完整原状态、未评估理由和原 Finding 查询保留。v1.4 处理完成不改变旧报告的判定或验证覆盖率。
- 对照仅针对显式选定的直接 baseline 根，最多 200 个。限制包括单根五秒、工作步数及 manifest 大小。未完成根标注缺口。传递关系保留原 root 观测，不展开路径，也不将确认传播到依赖它的包。
- 当前保守分组以原检查和原导航键为主。根因等价、跨产品运行 lineage、变化归因和与 RPM 求解结果对账属于额外工作。浏览器会显示组内实际成员和各自评估。
- 侧车列表可按组类型、影响级别和公开范围过滤。方向见原 Finding 和成员中的镜像字段。设计中的方向组合筛选基准和完整依赖路径见证超出本次直接关联范围。
- 公开范围表由使用者提供。库名、路径和 C++ ABI 标签提供验证线索，后续 SDK、DWARF、ARMv7 设备和 C++ Runtime 验证有独立的输入与授权要求。
- 未完成构建不可挂载，恢复方式是在新目录重做。无已发布侧车的就地更新或断点续写。版本 1 的主要资源上限见 [性能](05_PERFORMANCE.md)。
- 原 Evidence 的路径和摘要来自原报告。新视图在请求时检查引用是否仍能安全访问，缺失和非法引用保留提示。只读索引不认证外部报告提供者，需使用已知来源的报告快照。
