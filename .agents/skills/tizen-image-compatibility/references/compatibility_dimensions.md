# Coverage and boundaries

Every result is directional. `IDENTICAL` describes a measured surface, never the whole operating environment. The framework emits explicit unknown coverage records for checks that need more evidence.

| Dimension / CLI key | Implemented evidence and comparison | Requires additional evidence |
|---|---|---|
| ELF `elf` | All detected regular ELF files; class, endian, machine, OS ABI, ABI version/type, interpreter, sections, versions, raw notes/relocations; fallback basic ELF header when readelf is absent | Unsupported ELF encodings and truncated/failed tool results remain unknown |
| Binary ABI `abi` | Dynamic exports/imports, binding/visibility, symbol versions/default versions, data/TLS symbol size, C++ mangled/RTTI/vtable symbol inventories; optional abidiff for matched embedded-DWARF binaries | Full function types, calling conventions, structures/alignment/padding/member offsets require usable debug info; split DWARF is not automatically found; TLS/relocation/unwind details are raw evidence, not a semantic comparator |
| Public API `api` | Public installed .h/.hpp/.hh/.hxx paths, normalized tokens, simple prototypes, macro kind/value, include dependencies, conditional/architecture/compiler/version hints | Not a complete C/C++ parser. Overloads, typedef equivalence, namespace/template visibility, attributes and preprocessor selection need SDK compilation; changed signatures/types are conservative unknowns |
| Headers `headers` | Four header-source/compiler cells, selected independent include probes, compiler versions/argv/diagnostics, target ABI verification | Explicit SDKs and compilers; default first 50 sorted headers; use a larger header_limit or custom API source probes |
| Dynamic linking `linking` | SONAME, DT_NEEDED, loader paths, RPATH/RUNPATH; provider inventory across rootfs, aliases, missing libraries, dependency cycles, baseline dependencies against candidate | Loader-cache/search-order semantics, symbol interposition, full versioned resolution closure, weak imports and dlopen names require target loader checks. Finding a provider is not proof it can be loaded |
| Compiler runtime `compiler_runtime` | Discovers libc, C++ runtimes, unwind, gcc/compiler-rt, atomic, OpenMP and sanitizer files, with normal ELF interface comparison | Different implementation names alone are unknown, never incompatible. Runtime behavior needs target probes |
| Kernel `kernel` | os-release, /boot/config*, UAPI header paths/content and configuration values | No kernel is booted; syscalls/ioctl/errno/proc/sys/netlink/futex/epoll/mmap/signals cannot be inferred from inventory. Kernel version is configuration filename evidence, not uname |
| IPC `ipc` | D-Bus introspection object paths, interface/member names, argument signatures, signal/property attributes; service/policy files | Bus access, socket/RPC protocols and effective security need custom target probes |
| CLI `commands` | Executable and symlink inventory under /bin, /sbin, /usr/bin, /usr/sbin | Options, output, defaults, environment and exit behavior need configured read-only probes; no automatic `--help` execution of image commands |
| Filesystem `filesystem` | Tree, types, symlinks/resolution, modes, uid/gid, device numbers, normalized /etc and selected system configuration, tmpfiles/udev | /proc, /sys and /run contents are excluded; directory symlinks are not recursively traversed; archive security metadata can be incomplete |
| RPM/SDK `packages` | Real `rpm --xml` queries of package archives or private copied DB, name/version/release/arch, provides/requires/conflicts/obsoletes/files; pkg-config and CMake text; library/header symlinks | No install scriptlets, payload install or dependency solver. Package rename/version/provides changes are unknown pending consumer/solver validation |
| Boot/services `services` | Unit content and all section keys, including ExecStart/Stop, dependencies, user/group/caps, environment, restart, sockets/timers/targets | No systemd boot or service execution; offline equality cannot prove service availability |
| Security `security` | Permissions, setuid/setgid, readable capability/ACL/LSM xattrs, policies (SELinux/Smack/AppArmor/seccomp/etc.), IPC policy configuration | No policy is changed; effective enforcement, namespaces and principal-specific access require explicitly authorized probes |
| Runtime `runtime` | Opt-in isolated adapter; same GCC binary on both images and same Clang binary on both images; deterministic C/C++ observable comparison | Built-in probes are representative, not exhaustive; real device/QEMU/VM and SDK required |
| Hardware `hardware` | Userspace DRM/EGL/GLES/Vulkan/Wayland/audio/GStreamer-related paths; absent userspace surface marked N/A, physical hardware remains unknown | GPU, camera, input, codec and acceleration behavior require actual subsystems/device probes |
| Network `network` | SSL/TLS libraries, certificate-store/configuration paths and relevant /etc data | IPv4/6, DNS, DHCP, routing/netlink, TLS negotiation, Wi-Fi/Bluetooth need target probes |
| Resources `performance` | Optional ELF file size comparison with percent budget, separate severity and dimension | Boot/load time, memory/CPU/throughput/stability timing not implemented; explicitly unknown |

Built-in C probe assertions exercise aligned allocation/free, pthread creation/join, mutex, condition variable, semaphore, C11 atomics, thread-local state, signal handling, dlopen/dlsym, temporary file I/O, Unix socket I/O, fork/wait, monotonic time/nanosleep, C locale and math. It emits primitive/type layout sizes/offsets. C++ covers vector/string, exceptions, destructor unwinding, RTTI/dynamic_cast, threads/TLS and layout observations. It does **not** claim UTF-8 conversion merely from holding UTF-8 bytes. Extend with source probes for platform APIs, locale conversion, exec, kernel interfaces or hardware.
